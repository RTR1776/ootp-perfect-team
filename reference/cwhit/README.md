# cwhit boards, transcribed from screenshots

L.J. cannot export cwhit's site, so these are hand-transcribed from screenshots
he took on 2026-09-17, for the Friday Nightmare Cap build (cards 50–74, 1955,
1936 Hinchliffe Stadium, no variants, cap 1559). Each file says what filter the
screen had on. Transcription by Claude; a digit could be wrong — anything that
matters should be re-read off the site.

| file | what | filter on cwhit's screen |
|---|---|---|
| `2026-09-17 hitters observed.csv` | observed play, the last two weeks, sorted by wOBA | PA ≥ 300, defence ≥ 60, VAL ≤ 74 |
| `2026-09-17 pitchers observed.csv` | observed play, the last two weeks, sorted by ERA | IP ≥ 100, VAL ≤ 74 |
| `2026-09-17 hitters projected.csv` | cwhit's projection board, sorted by Cap Value | VAL ≤ 74 |
| `2026-09-17 pitchers projected.csv` | cwhit's projection board, sorted by pwOBA against | VAL ≤ 74 |

"Cap Value" is cwhit's own value-per-cap-point figure; its definition is not
published on the screen. HR600 / WAR600 / wSB600 / UBR600 are per 600 PA.
