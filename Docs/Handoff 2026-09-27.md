- **How old and new are kept apart:** `restrictions.formatSince` is the Chicago day the current format first ran. While any export on file for the series was filed before that day (`exportsPredate`), /build leaves the series out as the event's own play: its card lines, set evidence, field handedness and roster shape. The cards' play elsewhere still counts.
  - Checked 09-28 by running `exportsPredate` over every dated weekly: all 12 are set aside, so none reads old exports as new. Of the 5 undated ones, only Saturday Bronze Cap and Diamond Variety do; the other three have no exports yet.
  - `catalogue:set --format-since YYYY-MM-DD` sets the day (the note given with it is kept as `formatSinceFrom`). Alone, it changes only the date and keeps `previousFormat`. Any change of year, stadium, DH or card years now requires it: a date, `keep` or `none`.
  - A roster built by script for a changed event passes no `--series`, and passes `--obs-exclude <series>` to drop the old exports from observed play too.
