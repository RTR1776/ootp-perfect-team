# Model v2 (2026-10-11) — rebuilt on team results across every run environment

L.J.: "fix everything, you have the data, build a better model for all REs." Scripts in `web/scripts/model-v2/` (teams.mts → fit.py → ratings.py → compare.py) and `web/scripts/ptcs7champ-review/` (archive.mts/.py).

## Data
- **4,793 team rows**: 1,213 league seasons (HD450–453, PEL, LD404; ~160 games each; default 2010–13 weeks plus 1952, 1959 and 1989 theme weeks) and 3,580 tournament team-events (36 cap exports + six PTCS 7 Championship brackets; 1946–76, 1994–2009 and 2010+ environments). Jim-beater teams dropped. Older league snapshots without runs/starts were re-read from `League Data/<week>/`.
- **Card level**: 66 archived series + the Championship (observed_card_stats), each scored in its own environment.

## What changed
1. **Arms' spread by era** (`calibration.ts` ARM_ERA_SPREAD): ×1.5 in 1946–76, ×1.3 in 1977–93 environments.
2. **Glove runs by position** (`fielding.ts` FIELDING_CALIBRATION): C 1.61, 1B 1.0, 2B 1.29, 3B 1.20, SS 1.64, LF 1.24, CF 1.69, RF 1.25.
3. **Team weights** (`calibration.ts` TEAM_WEIGHTS → env-roster, Card Fit, /build): a glove run and a pitching run against a bat run — ≤1945 2/2, 1946–76 3/2.5, 1977–93 3/2, 1994–2009 1.5/1.5, 2010+ 3/2.5. Cross-validated: 5-fold by event 0.474 → 0.503; fit on tournaments, scored on league 0.546 → 0.569. The glove effect runs through fielding actually made (with observed ZR in the tournament fit the model-glove term goes to −0.02). `env-roster --no-team-weights` turns it off.
4. **Arm ratings** (`calibration.ts` ARM_RATING_FIX): pHR under-priced in every era (+0.38 to +0.68 runs/700 BF per +10 above 100), Stuff before 1977 (+0.45 to +0.53 per +10 above 92). 0.75 of the measured miss, both halves agreeing.
5. **Bats, 1994–2009** (ERA_SLOPES Steroid): Power 2.18 → 2.71, Avoid Ks 0.48 → 0.71, BABIP 1.24 → 1.47.
- Not used: roster traits (stamina, speed, handedness) — they helped within league or within tournaments but collapsed across them (0.42 → 0.14). pBABIP left alone (the FIP target cannot see it).

## Limits

- Catcher framing is still not in the archive's counters.
- Every roster saved before this needs a rebuild.

## Revised the same day: two models (L.J.: league is normalised, tournaments are not)
The team weights above were fitted on league seasons and tournaments pooled, and the league seasons dominated. The tournament tools now use a **tournament-only** fit, scored on **wins** (`tourfit.py`, 3,580 team-events, 42 exports):
- **Team weights: gloves 2, pitching 2** against a bat run, every era. Per-era weights did not beat one pooled weight on held-out events.
- **Track record off** (`OBS_K_DEFAULT` 5000 → 1,000,000): a card's play in other event types made win prediction worse at every blend strength (0.375 → 0.371 at 5000).
- **How predictable is a tournament?** 17% of the spread in team win% is skill; the best possible correlation is ≈0.41.
- **Result, tournaments only (original → new):** win% 0.370 → 0.380; games played 0.274 → 0.289; run diff 0.416 → 0.427. **PTCS 7 Championship:** win% 0.337 → 0.369, games played 0.233 → 0.264. The model's top quarter wins .568 and plays 15.8 games; its bottom quarter .433 and 9.2.
- The card-level fixes (arm spread, glove calibration, arm pHR/Stuff, 1994–2009 bats) were all measured on tournament play and stay. The league model (`league-model.json`, league-compare / league-best) is separate and was not changed by any of this except that it reads the same glove runs (fielding.ts).

## Three more checks (L.J. 10-11: "run all three and fix what holds")
What we did differently from the best Championship teams (`diff.py` vs bracket medians): +20 points of left-handed PA (deep teams −7, Liam −16); bats Power +23 / Speed −7 / K% +2.2 (Liam Avoid K +7, Speed +19); arm card value −5.3 (deep +1.1, Liam +2.2) with staff pBABIP −20 and Stamina −7; gloves below median at C, SS, 2B, CF, RF (Liam C +30, RF +20).
1. **Park hand offset — HELD, and was a bug.** env-fit scored each bat against its own side's average in the park and the linear weights are rescaled to the era, so a park's L/R split cancelled. 0.44 of the offset is real (archive, 10,013 bat lines in 56 series; folds 0.53/0.37; Championship 0.37). Added (`PARK_HAND_TRUST`). After: residual offset 0.05.
2. **pBABIP — no fix.** Against runs allowed (not FIP) the residual is −0.00 per +10; the FIP reading was an artefact. Our staffs' pBABIP was a spending problem.
3. **Speed — HELD (small).** Team runs scored beyond the model +0.059 per sd of lineup Speed, positive in all folds; +0.09 runs/700 PA per Speed point above 65 (`SPEED_RUNS_PER_POINT`, tournament tools only).
4. **Staff stamina (from check 2) — HELD as a staff effect.** Runs allowed −0.127 per sd of staff stamina (folds −0.137…−0.114); per card a high-stamina arm is not better per batter, so it is priced as each arm's share of the staff effect: +0.12 runs/700 BF per Stamina point above 71, at half strength (`STAMINA_RUNS_PER_POINT`, tournament tools only). Observed starter share was not used (partly a result of being hit).
- **Result (tournaments, same teams):** win% 0.380 → 0.387 (ceiling ≈0.41); Championship 0.369 → 0.379; runs allowed 0.344 → 0.361. Tests 279/279.
