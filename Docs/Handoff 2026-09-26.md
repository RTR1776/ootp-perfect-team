### Verified 2026-09-26 (second session) — what actually works in the container

Both variables work in any session started in this same cloud environment.
Three gotchas, each cost a round trip:

- **No raw Postgres.** `psql "$DATABASE_URL"` hangs: port 5432 is not open
  from the container. The Neon serverless driver (HTTPS) works, and it is
  what the app uses, so `tsx` scripts that import `@/db/client` are fine.
  Quick check: a `.mjs` in `web/scripts/.scratch/` doing
  `neon(process.env.DATABASE_URL)` + one `select`.
- **`--env-file=.env.local` scripts** (`cutoff:project`, `env:roster`) fail
  because there is no `web/.env.local` in the container. Run them as
  `node --import tsx scripts/<name>.ts` instead; `DATABASE_URL` is already
  in the environment.
- **Chromium rejects every site** (`ERR_CERT_AUTHORITY_INVALID`) until the
  proxy CA is in its NSS store; curl/node already trust it. Never turn off
  TLS checks. Fix, once per container (or put it in the environment's setup
  script so every session starts with it):
  ```
  apt-get update -qq && apt-get install -y -qq libnss3-tools
  mkdir -p ~/.pki/nssdb && certutil -d sql:$HOME/.pki/nssdb -N --empty-password
  cd /tmp && csplit -s -z -f ca- /root/.ccr/ca-bundle.crt '/-----BEGIN CERTIFICATE-----/' '{*}' \
    && for f in ca-*; do certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "$f" -i $f; done
  ```
  Playwright is installed globally: `require(\`${npm root -g}/playwright\`)`.
  Log in by filling `input[type="password"]` on `/login` and pressing Enter.

## Second session, Sep 26 — engine fixes (PR from `claude/modest-fermi-cvfsir`)

Why /build's recommendations disagreed with each other: Re-recommend is the
greedy fill; Optimise hill-climbed from ONE board with one- and two-card
moves, so it stopped at the first local optimum and where it stopped depended
on where it began (Negro Leagues Slots: +39.5 from the greedy fill, +47.9
from the saved Claude pick). The vs-RHP board was the trap: the bench shares
its group, so a three-way reshuffle (Josh Gibson in from the bench) was
unreachable. The +47.9 board also carried the BASE Lennie Pearson, whom L.J.
owns only as a variant, so it failed its checks and the toggle could not fix
it (disabled when the base is not owned).

Fixed:
- `lib/assign.ts` — Hungarian max-weight assignment. `rosterObjective` now
  exposes `slotValue` (exact per-slot contribution) and `optimizeRoster`
  re-solves both boards' positions at the start, after every accepted move,
  and for every single move that brings in a new bat. The CLI
  (`env-roster.ts`) passes it too.
- Optimise is multi-start: your board, the greedy fill, then λ fills
  (2, 1, 4, 0.5, 8), 30 s budget, progress shown between starts.
- Ownership: the builder only ever uses an owned copy (a saved base copy of
  a variant-only card loads as the variant, with a note), and `legal()`
  rejects unowned copies, so an illegal start board is replaced.
- Shop: a card with last-10 0 and no ask (untradeable rewards like PTWC 4th
  Place Dihigo, 48 cards) has no price instead of "0".
