## Later the same session: the league model (#28)

L.J. asked whether league play, which normalises and suppresses cards, could be modelled from the league data well enough to settle Canseco vs the Kevin Mitchell variant. Full write-up: **`Docs/League Model 2026-09-26.md`**.

- **Suppression, measured:** league play returns **0.68** of the tournament model's edge, in every league and on both boards.
- **The league model:** the scaled tournament runs, plus the league's own price per rating measured against the league's average, re-priced per run environment.
  - Held out: r 0.92 on unseen cards, 0.85 on unseen weeks.
  - Theme weeks: 2026-08-23 fits 1959 and 2026-09-20 fits 1989 (`league-era`). Each week is scored in its own environment.
- **Verdict:** the Mitchell variant adds **+13.8 runs (+1.4 W)** to the PEL lineups, Canseco **+6.9 (+0.7 W)**, the base Mitchell +8.5. It holds in a 1989 theme week, in HD, and with gloves halved.
- **Tools:**
  - `pnpm league:panel`, then `python3 scripts/league-fit.py` (refit)
  - `pnpm league:compare --roster … --add …` (a lineup with vs without a card)
  - `lib/analytics/league-model.ts` (the scorer)
- **The league parser now keeps split ratings and VLvl** (`ingest/league.ts`). Rows imported before today have overall ratings only. The panel fills those from the shop card: exact for base copies, variants within 1–5 points.
- **Push to GitHub.command syncs both ways** (#29). It commits this Mac's data (League Data/, Tourney Data/, web/src/data/, reference/) after a yes, pulls with `--rebase --autostash` so other local edits never block it, then pushes after a yes.
  - It reaches the Mac with one pull in Terminal: `cd ~/Desktop/"OOTP Perfect Team" && git pull --rebase --autostash origin main`.
  - A plain `git pull --rebase` fails with "You have unstaged changes", because the filer and the dump loader edit tracked data files.
  - After that, double-click the script whenever Claude merges something.
