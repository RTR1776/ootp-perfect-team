The PEL week had two uploads, both filed as 10-25:

- **294–296 (1,050 rows):** the full season.

The panel kept only the newer copy. But the arm loader, park-sweep and league-best select a week by date, so they would have read both copies and double-counted the PEL field. The mid-week copy's snapshots (170–172) are now re-dated **2026-10-22**, the convention the HD452 10-08 and 10-10 mid-week files already follow, and `dropSuperseded` skips them. To undo:

```sql
update league_snapshots set captured_on = '2026-10-25' where id in (170,171,172);
```
