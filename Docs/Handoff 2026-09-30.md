  - Joint residual on log ratings (log value control): Power +2.5 runs per e-fold (t 9.4), so the model slightly *under*rates power. Nothing else is significant.
  - Contact-only bats (POW<60, CON≥110, n=84): −2.5 ± 0.4, so the model *over*rates them. Big-split bats (n=35): +4.7 ± 1.5, partly platoon usage in play.
  - Bassler model −8.1 / obs −9.4; Fielder +3.3 / +0.5; Bo Jackson +23.9 / +25.1.
  - **Conclusion:** cwhit's flatter read isn't supported; where they differ, play sides with us or goes further. Candidate refit: a little more power, a little less contact. Not done; ask L.J.
