# Inbox — drop anything here

Drop OOTP exports, screenshots, or notes in this folder. No naming, no sorting.
Claude files each item where it belongs, ingests it, and empties the folder.

- Weekly: card shop list (`pt_card_list.csv`), your collection export, league export (all / vL / vR)
- Whenever: screenshots of standings, ballparks, tournament lists, PTCS / PTMS results

The full routine is in `Data Drop Guide.html` at the repo root.
